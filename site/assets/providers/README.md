# Provider marks

Used to identify implemented adapters, not to suggest endorsement or partnership.
Provider trademarks remain the property of their respective owners. Artwork is
not recolored; layouts preserve aspect ratio.

- **Heyo:** `https://heyo.computer/assets/icon.png`, identified as the organization
  logo in the official site's structured data.
- **E2B:** `https://e2b.dev/brand/e2b-symbol-black-s.svg`, from the official
  `https://e2b.dev/brand` assets page.
- **Docker:** `docker-logos/SVG/docker-mark-black.svg` from
  `https://www.docker.com/static/Docker-Logos-1.zip`, linked by Docker's official
  media-resources page.
- **Local:** no vendor mark; the UI uses a generic terminal icon.
